How It Works

The blocklist plugin intercepts every event before it's stored and checks if the pubkey is banned.

  1. User publishes an event
  2. strfry sends event to the plugin via stdin
  3. Plugin checks pubkey against blocklist.json
  4. If banned → event rejected with error message
  5. If not banned → event accepted

Changes to bans sync automatically. A strfry restart is only needed when changing the plugin path.
